# Diretório de Logo

Este diretório é destinado para armazenar a logo do Sistema IVN.

## Como usar:

1. Coloque sua imagem de logo neste diretório com o nome `logo.png`
2. Formatos suportados: PNG, JPG, SVG
3. Tamanho recomendado: altura de 40px (largura proporcional)
4. A logo será exibida no menu superior do sistema

## Nome do arquivo:

O arquivo deve ser nomeado como: **logo.png**

Se você usar outro formato, altere o caminho no arquivo:
`sistema-ivn/frontend/src/components/Layout/MainLayout.jsx`

Linha 65: Altere `/images/logo/logo.png` para o caminho do seu arquivo.
